# Walla Walla Symphony SymphoniCon Lord of The Rings Interactive Flip Book

An interactive digital flip book showing the journey of some of the characters in J. R. R. Tolkien's famous books, Lord of The Rings, as it might look if it took place in Walla Walla, Washington. This project was designed as a Human-Computer Interaction class project by three Whitman College students, Ky Kendall, Connor Campbell, and Lily Kamila. The Walla Walla Symphony displayed this project on November 5th, 2026 at SymphoniCon in Cordner Hall on Whitman Campus.
